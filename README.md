# Django TODO

Учебный проект приложения для ведения списка дел на Django.
Пользователи регистрируются, создают свои дела, отмечают их выполненными,
редактируют и удаляют. Каждый пользователь видит только свои задачи.

## Функциональность

- Регистрация, вход и выход пользователей
- Создание дел: название, примечание
- Редактирование дел
- Отметка выполнения дела (с фиксацией даты выполнения)
- Удаление дела с подтверждением (через POST-запрос)
- Пагинация списка дел
- Изоляция данных: пользователь видит изменяет только свои дела

## Технологии

- Python 3
- Django 5.2
- SQLite
- Pillow

## Структура проекта
├── todo/ # приложение: модели, формы, представления
├── core/ # настройки проекта (settings, urls, wsgi)

## Установка и запуск

1. Клонируйте репозиторий:

 ```bash
   git clone https://github.com/vladimirperov85/django-todo.git
   cd django-todo
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/macOS
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции:

   ```bash
   python manage.py migrate
   ```

5. Создайте суперпользователя (для доступа к админке):

   ```bash
   python manage.py createsuperuser
   ```

6. Запустите сервер разработки:

   ```bash
   python manage.py runserver
   ```

7. Откройте в браузере: http://127.0.1:8000/

## Что изучалось в проекте

- Регистрация и аутентификация пользователей (`AuthenticationForm`)
- CRUD-операции с делами
- Изоляция данных по владельцу (`owner=request.user`)
- Фиксация даты выполнения (`completed_at`, `timezone.now()`)
- Пагинация (`Paginator`)
- Контроль доступа (`@login_required`)
- Удаление через POST-запрос с подтверждением
